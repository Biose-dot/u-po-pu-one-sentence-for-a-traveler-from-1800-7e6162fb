Entry for the [make.fun](https://make.fun) bounty
[One Sentence for a Traveler from 1800](https://make.fun/c/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

One sentence, at most 200 characters, explaining the modern internet to a time traveler from 1800 — using only words they could already know: libraries, letters, market stalls, books.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Picture every library, letter, and market stall in the world folded into one great talking book that answers any question in a blink, and any soul alive may open it.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
