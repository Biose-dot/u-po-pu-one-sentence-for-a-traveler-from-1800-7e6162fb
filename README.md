Entry for the [make.fun](https://make.fun) bounty
[One Sentence for a Traveler from 1800](https://make.fun/c/u-po-pu-one-sentence-for-a-traveler-from-1800-7e6162fb).

One sentence, at most 200 characters, explaining the modern internet to a time traveler from 1800 — using only words they could already know: books, letters, maps, songs.

`main.py` (Python 3) writes the entry to `/output/entry.txt`:

> Imagine a single book holding every letter, map, and song ever made, which speaks back at once when asked, and any person on earth may read it for free.

Run it locally with:

```sh
MAKEFUN_OUTPUT_DIR=out python3 main.py
```
